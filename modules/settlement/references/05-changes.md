# 5. 사업계획변경 및 예산전용내역

기본 작업은 기존 표의 당초·변경 예산 수치 입력이다. 아래 문체 지침은 변경사유 작성이 작업 범위에 포함될 때만 적용한다. 기존 사유·공문번호·승인일은 수치 입력 과정에서 바꾸지 않는다.

짧은 명사형 사유와 공단의 5열을 따른다. 기존 제목·안내·단위·표 배치를 그대로 유지한다. 승인일별 소제목은 새로 넣지 않는다. 열은 사업단위(비용구분) / 예산액-당초 / 예산액-변경 / 변경사유 / 승인사항(내부결재). 사업단위 뒤 줄바꿈 후 비용구분을 괄호 안에 쓴다.

기존 표의 행 순서와 승인 이력을 보존한다. 검산할 때는 승인일 순으로 변경액을 연결하되 이를 이유로 표를 재배치하지 않는다. 같은 비용구분이 여러 번 바뀌면 각 승인 건마다 반복한다. 첫 변경의 당초는 본예산, 다음 변경의 당초는 직전 승인 후 금액이다. 마지막 변경액이 2항의 변경 후 예산과 같아야 한다. 중간 이력을 최종 금액 한 줄로 덮어쓰지 않는다.

문형은 “대상/항목 → 변경 필요 또는 잔액 원인 → 증액/감액” 순서이며 한 셀에 한 문장 상당의 짧은 명사형을 쓴다. 상세 산출식·기대효과·인사말을 넣지 않는다.

변경사유 문체 예시:
- 운영계획 변경에 따른 감액
- {프로그램} 운영 증가에 따른 {비용} 증액
- 내부강사료 증액 / 외부강사료 감액
- {항목} 집행잔액 감액 (집행자료로 확인된 경우)

“잔액 감액”, “타 재원 활용”은 실제 근거가 있을 때 사용하는 표현이다. 일반적 사유 작성 허용 시에는 “운영 소요 조정에 따른 감액” 등으로 작성한다. 증감 부호와 사유 방향이 반드시 같아야 한다.

승인사항은 “내부결재 공문” 또는 “중진공 공문” → 날짜 → (공문번호) 순으로 줄을 나눈다. 수정 결재가 있으면 그 아래 “(수정 날짜)” → “(수정 공문번호)”를 둔다. 결재가 확인되지 않은 건은 승인된 것처럼 기입하지 않는다. 원장에 3차증감이라고 적혀 있어도 승인자료가 없다면 정산 확정표에는 포함하지 않는다.

사업단위 내 전용도 별도 승인 이력으로 보존한다. 원장에 차수별로 합산되어 있어도 승인일·문서번호·금액은 승인 자료와 별도로 대조한다.
