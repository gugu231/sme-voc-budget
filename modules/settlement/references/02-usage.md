# 2. 사업비 사용현황(총괄)

제목 → 우측 단위(원) → 표 순서. 6열은 사업단위 / 비용구분 / 당초 예산 / 예산전용 등 변경 후 예산(A) / 사용액(B) / 사업비잔액(C=A-B). 공단의 사업단위 순서(연수비, 프로그램운영비, 대외활동비, 실습장비 구입 및 유지비, 사업관리비, 여비)와 ①~㉑ 비용구분을 유지한다. 같은 사업단위 셀은 세로 병합한다. 해당 없는 비용구분은 공단 작성요령상 제외 가능하지만 0원 행을 남기는 방식이 기본이다.

당초예산은 원장의 본예산을 비용구분별 합산한다. 변경 후 예산은 기준일에 유효한 승인 이력으로 계산한다. 원장의 최종편성예산은 승인되지 않은 변경을 포함할 수 있으므로 그대로 붙이지 않는다. 사용액은 같은 기준일·같은 재원·같은 비용구분의 실제 집행자료를 합산한다. 잔액은 A-B다. 실제 미집행으로 확인된 경우만 0을 쓰며 자료 미제공을 0으로 바꾸지 않는다.

세부항목·프로그램명은 이 표의 비용구분이 아니다. 명칭 대응은 목·세목이나 위치가 아닌 사업단위+비용구분으로 매핑한다. “홍보 및 행사비/홍보및행사비” 같은 공백 차이는 표준 명칭으로 통일하되 “전담인력운영비/수업대체인력운영비”는 다른 항목이다.

사용액 합계는 정산총괄표 집행액, 잔액 합계는 정산총괄표 집행잔액과 일치해야 한다. 변경 후 예산 합계는 재원별 확정 총사업비와 일치해야 한다. 공단 양식의 “당초계획금액보다 각 세목 간 50% 이상 변경 사용 시 5항에 사유 기재” 안내를 확인 대상으로 유지한다. 이것을 별도 법정 전용승인 한도로 대체 해석하지 않는다. 당초 0인 신규 편성은 분모가 0이므로 별도 검토한다.

표준 원장(`modules/ledger/assets/예산원장_최종서식.xlsx`): F=산출근거(최종예산), G=본예산, H=1차증감, I=2차증감, J=3차증감, K=4차증감, L=최종편성예산, M=특화형, N=비고. 단위내전용 별도 열은 없다. 차수별 합산액만으로 과거 기준일의 승인 이력을 역산하지 않는다.
