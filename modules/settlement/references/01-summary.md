# 1. 정산총괄표

공단 양식의 제목, 우측 “(단위 : 원)”, 2단 머리글을 유지한다. 행 순서는 정부지원금 → 대응자금(민간, 타부처) → 총계. 열은 구분 / 예산액(A) / 집행액(B) / 집행률(B/A) / 집행잔액(D=A-B) / 불인정금액(E) / 발생이자(F). 반납액(D+E+F)은 마지막 3열의 상위 머리글이며 임의로 다른 열로 해석하지 않는다.

예산액은 해당 재원의 확정 지원금액, 집행액은 기준일까지 실제 지출한 금액이다. 단순 항목 간 전용으로 총사업비가 늘지 않는다. 집행률은 소수 첫째 자리와 %로 표시하고 총계에도 %를 붙인다. 총계 집행률은 집행액 합계÷예산액 합계로 계산한다. 개별 집행률을 더하거나 평균내지 않는다. 예산액 0일 때 집행률은 계산 불가로 처리하며 0/0을 정상 비율로 만들지 않는다.

사용액과 불인정액을 이중 차감하지 않도록 집행원장 집행액의 정의를 확인한다. 발생이자는 통장·이자내역 기준 누적액이며 예산액에 섞지 않는다. 공단 양식은 대응자금의 반납액란을 기재하지 않도록 안내하므로 해당 자금 제공기관의 회계처리와 구분한다. 대응자금은 학교별 확인된 금액을 입력한다.

원 단위 숫자에 세 자리 쉼표를 사용한다. 표 앞뒤에 설명 문장을 늘리지 않는다. 확인할 내용은 별도 검토 메모로 보낸다.
