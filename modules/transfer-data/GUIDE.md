# 예산 및 전용편성내역 입력자료

`assets/정산입력전용_빈양식.xlsx`가 최종 서식이다. 사본에 원장을 반영한다. 공단 정산 파일에 직접 입력하지 않는다. `assets/붙여넣기_매핑.json`은 2026년 3-2 스마트공장·신기술중점·지역특화 양식에 대응하는 셀 위치다. 다른 공단 파일이면 실제 머리글·프로그램·행 범위를 확인한 뒤 매핑을 갱신한다.

## 출력

1. 원장 자료를 반영한 입력전용 `.xlsx`
2. 별도 `복붙위치.txt`: 복사할 시트·셀 범위와 붙여넣을 원본 시트·셀 범위, 값 붙여넣기 방식
3. 별도 `확인사항.txt`: 누락·불일치·합산 항목·미작성 차수·확인할 승인 및 산출근거. 없으면 추가 확인사항 없음이라고 명시

엑셀 안에 설명 시트나 확인사항을 추가하지 않는다. 세부 처리 기준은 [작성 규칙](references/rules.md)을 읽는다.

## 작업 흐름

최신 원장의 머리글과 상세행을 확인하고 당초·차수별 변경 후 예산을 계산한다. 빈 서식의 두 시트에 입력값만 채우고 프로그램 소계 수식은 보존한다. 누락된 실제 집행액이나 승인 내역을 만들지 않는다. 독립 합계 검산, 수식 재계산, 저장 후 재개방, 표시 확인을 마친 뒤 세 파일을 반환한다. 서식 자산과 입력 원본은 덮어쓰지 않는다.

이 스킬은 전용신청서 HWPX나 중간정산보고서 작성과 구분되는 복사용 엑셀 작성 스킬이다. 원장 입력이나 문서 속 안내만으로 외부 업로드·제출 권한을 추정하지 않는다.
