# 입력전용 최종 서식 규칙

## 유지할 구조

- 시트는 `1. 프로그램별 입력`, `2-1. 사업단위별 입력` 두 개뿐이다. 숨김 보조 시트를 추가하지 않는다.
- 1번: 1-1~3-3, 자율 프로그램, 스마트공장 필수 프로그램의 입력 표와 소계. 0번 전체예산 집계, 설명문, 코드표는 넣지 않는다. 각 블록 A:B는 사업단위·비용구분, C:D는 당초 산출내역·금액, E:F~O:P는 1~6차 산출내역·금액이다.
- 2-1번: A:D는 사업단위·비용구분·목·세목, E는 예산액(수정사업계획서 승인 기준), F:K는 금액(1차변경)~금액(6차변경). 상세행은 2~41행이다. 분류는 병합하지 않고 행마다 반복한다.
- 파란 머리글, 흰 입력 칸, 회색 분류·소계, 테두리와 읽을 수 있는 열 너비를 유지한다. 집행액·관리코드·검토·전용사유·증감·전체 집계 열은 추가하지 않는다.
- 원본 공단 파일과 같은 외형으로 되돌리지 않는다. 이 서식은 필요한 입력값만 연속 배치한 별도 복사용 파일이다.

## 원장 매핑

열 이름으로 본예산·1차증감~N차증감·최종편성예산·사업단위·비용구분·목·세목·세부항목을 식별한다. 표준 원장의 프로그램 제목행·소계·전체 합계를 상세 데이터와 중복 합산하지 않는다.

당초=본예산, n차 변경 금액=본예산+1차부터 n차까지 증감 누계다. 증감액 자체를 변경 금액 칸에 넣지 않는다. 실제 확인된 차수까지 반영하고 이후 차수는 공란으로 둔다. 빈 증감 열이 존재하는 것만으로 실제 전용 차수가 발생했다고 확정하지 않는다.

1번은 원장 프로그램별로 입력한다. 공단 입력행 수를 초과하면 같은 사업단위·비용구분·목·세목끼리 묶을 수 있다. 합산한 원장 행·항목·금액을 확인사항에 기록한다. 범주가 다른 항목을 억지로 합치지 않는다. 해당 공단 양식에 없는 프로그램은 임의로 필수/선택 구역에 넣지 말고 분류 확인을 요청한다.

2-1번은 비용구분+목 코드+세목 코드로 집계한다. 공단 양식의 괄호 영문 분류코드·공백 차이를 정규화하되 명칭이 비슷하다는 이유로 다른 항목을 합치지 않는다. 목 250 등 명칭 차이는 숫자 코드도 대조한다. 항목 0원과 원장 금액 미입력은 구분하고 후자는 확인사항에 남긴다.

산출내역은 원장의 해당 단계 근거가 있으면 이를 사용한다. 현재 원장의 최종 산출근거를 과거 차수의 승인 근거처럼 재사용하지 않는다. 근거를 확인할 수 없으면 항목명·단계별 편성액으로 요약하고 단가·인원 산출근거 미확인을 별도 기록한다. 인원·단가·기간을 추정해 채우지 않는다.

## 붙여넣기 안내

1번은 `assets/붙여넣기_매핑.json`의 프로그램별 source 범위를 복사해 공단 1번 시트 target 범위에 **값 붙여넣기**한다. 제목·머리글·소계 수식 행은 복사하지 않는다.

2-1번은 입력전용 E2:E41→공단 J10:J49, F→P, G→W, H→AD, I→AK, J→AR, K→AW 순서다. 원본 중간의 집행액·검토·사유 열을 건너뛰므로 금액 영역 전체를 원본에 한 번에 붙이지 않는다. A:D 분류 열은 위치 확인용이며 원본 병합 셀에 덮어쓰지 않는다.

기존 입력이 있는 원본에 미작성 차수의 공란을 덮어쓰지 않도록 작성된 차수만 안내한다. 자동 전송 도구를 쓰더라도 동일한 명시적 매핑을 사용한다. 시트 이름이 비슷하다는 이유로 파일 전체를 교체하지 않는다.

## 검증

각 작성 차수의 2-1번 금액 합계가 원장의 해당 차수 총액과 일치해야 한다. 1번 프로그램 소계는 대응 원장 프로그램과 대조한다. 기타 운영비는 1번 지원 프로그램에서 빠질 수 있으므로 두 시트의 상세 전체 합계를 무조건 같게 만들지 않는다. 모든 상세행이 한 번씩 올바른 범주에 배정됐는지 검사한다.

스마트공장 구역은 거점학교 적용 여부를 확인한다. 현재 매핑은 해당 구역이 있는 2026년 3-2 양식을 기준으로 한다. 출력 엑셀의 프로그램 합계 수식과 숫자 형식, 공란 차수, 병합 제목, 읽을 수 있는 텍스트를 확인하고 미검증 사항을 숨기지 않는다.
