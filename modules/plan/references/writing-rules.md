# 입력·작성·검증 규칙

명령은 해당 모듈 폴더(`modules/transfer`, `modules/plan`, `modules/settlement` 중 대상 업무 폴더)를 현재 디렉터리로 하여 실행한다.
## 원장 읽기

머리글로 열을 매핑한다. 현재 표준 원장은 원장 3행이 머리글이며 A 목, B 세목, C 사업단위, D 비용구분, E 세부항목, F 산출근거(최종예산), G 본예산, H~K 1~4차증감, L 최종편성예산, M 특화형, N 비고, O 검증, P AI 검토의견이다. 프로그램별 20개 상세 입력행은 5+21×i~24+21×i(i=0~11), 총계는 256행이다. 다른 형식은 실제 머리글과 행 구조를 확인하고 명시적으로 매핑한다.

수식 캐시가 없거나 오래되면 재계산한다. 상세행의 본예산+차수별 증감과 최종편성예산을 대조한다. 금액 0인 항목은 미편성으로 처리할 수 있지만, 금액 공란인 항목은 0으로 확정하지 말고 확인사항에 남긴다. 미편성 비용구분의 표는 삭제하지 않고 ‘미편성’, 금액 0으로 둔다.

## 양식에 넣을 내용

- 총사업비 구성현황: 국고보조금, 대응자금, 총계. **천원** 단위이므로 원 단위 금액을 1,000으로 나눈다. 소수 금액은 임의 반올림하여 총액을 바꾸지 않는다.
- 사업단위별 구성현황: 사업단위·비용구분·목·세목·재원별로 합산한다. 합쳐진 셀은 위 행의 목·비용구분을 이어서 읽는다. 숫자 코드와 명칭을 함께 대조한다. 특화형은 별도 재원이라는 뜻이 아니며, 해당 금액도 같은 비용구분에 합산한다.
- 국고보조금 비목별 현황: 국고 금액만 목·세목별 집계한다. 산출내역에는 포함 비용구분을 간략히 적고 상세는 뒤의 설명자료에 둔다. 대응자금을 국고 표에 섞지 않는다.
- 사업단위별 설명자료: 21개 비용구분별로 실제 항목, 내용, 산출내역, 금액을 채운다. 바로 아래 목·세목 표도 같은 비용구분의 금액과 일치시킨다. 항목별 내용은 원장 세부항목을 근거로 간결하게 작성한다.

비용구분 순서: 학생연수비, 교직원연수비, 현장실습경비, 실습재료비, 교재개발비, 내부수당, 외부수당, 간식비, 업체발굴비, 홍보 및 행사비, 연구개발비, 실습장비 구입비, 유지보수비 및 시제품 설계·제작비, 실습장비 임차비, 업무관리수당, 수업대체인력운영비, 전담인력운영비, 업무추진비, 일반수용비, 국내여비, 국외여비.

## 산출근거와 확인사항

산출근거가 최종예산과 일치하면 원문의 단가×수량×횟수를 사용한다. 불일치·누락이면 최종 금액은 그대로 반영하되 ‘최종편성액 ○○원(세부산출 확인)’처럼 표시한다. 금액에 맞추려고 인원·시간·횟수를 역산해 사실처럼 쓰지 않는다. 산출근거의 정확한 새 내용이 제공되면 확인 표시를 해제한다.

업무관리수당 성명·직위, 실습재료 세부품목·학과·단가·수량, 국외연수 방문지역·목적·일수·인원은 원장에 없으면 확인 필요다. 예시 문구나 다른 학교의 사실을 채워 넣지 않는다.

별도 확인사항에는 항목명, 원장 행 또는 식별자, 반영 금액, 확인할 정보를 적는다. 총계·재원 기준과 적용 차수도 기록한다. 단순히 ‘확인 필요’만 나열하지 않는다.

## HWPX 편집과 검증

제공된 기본 양식은 section0에 102개 최상위 문단, 표 46개다. 이는 구조 점검용이며 내용 검색과 머리글 확인 없이 고정 문단 번호만 믿지 않는다. 첫 재원표, 51행 사업단위표, 17행 비목표, 비용구분별 상세·목세목 표를 식별한다. 양식이 바뀌면 매핑을 다시 검증한다.

기존 셀의 글꼴·문단·테두리를 보존하고 예시 텍스트와 이전 계산 필드는 실제 내용으로 교체한다. 행 복제 시 rowCnt·cellAddr·병합 정보를 맞춘다. HWPX ZIP의 나머지 스타일·관계·바이너리를 보존한다. 금액이 줄바꿈되면 필요한 금액 열만 넓히고 이웃 열이 지나치게 좁아지지 않는지 확인한다. 모든 열을 일괄 조정하지 않는다. 글자처럼 취급되는 긴 표가 제목과 분리되면 표 나눔·배치 설정을 조정한 뒤 렌더링한다. 쪽수가 늘어나는 것은 허용하되 내용 누락을 막는다.

검산: 상세행 합계=원장 최종예산, 사업단위 총계 합=전체 금액, 목·세목 집계=해당 재원 총액, 각 설명자료 합계=해당 비용구분, 국고+대응=총사업비. 수식 캐시만 신뢰하지 말고 입력 금액에서 독립적으로 계산한다. 금액·단위·재원·분류가 일치하지 않으면 완료로 처리하지 않는다.

네이티브 검토 명령:
`powershell -File ../../scripts/finalize_hancom.ps1 -InputPath 초안.hwpx -OutputPath 작성본.hwpx -PdfPath 검토.pdf`

이 명령은 새 출력 경로를 요구하며 한글 COM을 사용한다. 작업 중인 한글 세션은 수정하거나 종료하지 않는다.
