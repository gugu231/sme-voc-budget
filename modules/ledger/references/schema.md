# 최종 원장 구조

## 원장

- 1행 제목, 2행 색상 설명, 3행 머리글. 4행부터 행 높이 28, 프로그램별 입력행 20개.
- A 목, B 세목, C 사업단위, D 비용구분, E 세부항목, F 산출근거(최종예산), G 본예산, H 1차증감, I 2차증감, J 3차증감, K 4차증감, L 최종편성예산, M 특화형, N 비고, O 검증, P AI 검토의견.
- 프로그램 구역 제목은 4+21×i행, 입력은 5+21×i~24+21×i행(i=0~11), 전체 합계는 256행이다. 소계와 상세행을 중복 합산하지 않는다.
- A:G 노랑 필수 입력, H:K 및 M:N 연두 선택 입력, L/O/P 회색 자동 계산·검토 영역. A:K/M:N 상세행만 작업자가 편집 가능하다. AI 의견은 작업 도구가 보호를 해제하고 입력 후 다시 잠근다.
- 빈 행은 오류가 아니다. 일부 입력한 행의 필수 셀이 비어 있으면 해당 셀이 빨간색이며, 입력하면 해제된다. O는 정상/이상, 빈 행은 공란이다.
- 산출근거 불일치 등 수식만으로 판단하지 못하는 점은 P에 구체적으로 남긴다. 수식이 산출근거 문자열의 금액을 자동 검증한다고 설명하지 않는다.
- 번호·예정포함예산·단위내전용 별도 열을 추가하지 않는다. 증감 음수는 숫자 앞에 -를 표시한다.

## 편성한도

- A 사업단위, B 비용구분, C 최종편성예산, D 편성가능한도, E 총사업비 대비, F 최대 편성비율, G 검증, H 비고.
- 3~23행 분류, 24행 총계, 25~26행 합산한도. D는 본예산 총액×F, E는 C÷본예산 총액. H3:H26만 작업자 입력 가능하다.
- G는 정상/오류, 원장이 비면 공란. 항목 및 합산한도는 0 이상이며 한도 이하이면 정상이다. 한도가 없는 항목은 한도 비교를 하지 않는다. 미편성 0원도 정상이다. 총계만 C24=D24(총사업비)여야 정상이며 크거나 작으면 오류다. 음수·계산 오류는 오류로 표시한다.
- 원장 O열의 입력 누락·분류 오류를 편성한도 판정에 연결하지 않는다. 입력 오류는 원장에서 확인한다. 오류 행 C:G는 빨간색이며 정상으로 돌아오면 기본 회색/총계 파랑으로 복원된다.

## 프로그램비율

- A 프로그램, B 구분, C 사업계획서, D 1차변경, E 2차변경, F 3차변경, G 4차변경, H 최종편성예산. 전체 잠금.
- 3~14행 프로그램, 15행 합계, 17~19행 필수/선택/기타, 20행 필수비율, 21행 35% 이상 검증, H23 원장 총액 대조, H24 차수별 증감 합계 검증.
- 필수비율은 필수÷(필수+선택)으로 계산한다. 기타 운영비는 분모에서 제외한다.
- 비율 미달은 해당 차수의 20~21행, 대조·증감 불일치는 H23/H24, 음수·수식 오류는 해당 계산 셀을 빨간색으로 표시한다. 원장 입력 누락만으로 프로그램 제목을 빨간색으로 표시하지 않는다. 각 시트는 자신의 검증 목적에 해당하는 문제만 표시한다.
- 현재 서식의 필수 프로그램 분류는 취업맞춤반, 중소기업 이해연수, 스마트공장 거점학교 현장체험연수다. 거점학교가 아닌 경우 적용 매뉴얼과 학교 사업계획에 맞는 분류 확인이 필요하다.
