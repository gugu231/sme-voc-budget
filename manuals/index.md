# 예산 편성 매뉴얼 검색 목차

네 PDF를 편성·전용 업무에 필요한 단위로 분리했습니다. 원본 PDF는 스킬에 포함하지 않으며 작업자가 보관합니다. 인용은 문서명과 PDF 쪽을 함께 적습니다. 세부운영기준은 PDF 쪽에서 4를 빼면 인쇄 쪽입니다.

## 최소 읽기 순서

1. 이 목차와 확인사항.md를 읽습니다.
2. 아래에서 업무에 해당하는 기준서 파일과 교육자료 슬라이드를 읽습니다.
3. 사례 판단이 필요할 때 FAQ를 검색해 해당 문답만 읽습니다.
4. 표·이미지·추출 순서가 의심되면 원문검색.jsonl의 해당 쪽을 확인하고, 그래도 불명확하면 작업자에게 원본 PDF 확인을 요청합니다.

## 업무별 진입점

| 업무 | 우선 참조 | 보충 |
|---|---|---|
| 목·세목 및 사업단위 매핑 | standard/05 | 교육자료 PDF 12~13쪽 |
| 프로그램 분류와 필수 비율 | 공단서식구조.md | 교육자료 PDF 10~11쪽, 기준서 PDF 69·136쪽 |
| 비용구분별 한도 | 교육자료 PDF 11쪽 | standard/06~14 및 해당 FAQ |
| 전용 가능 여부와 누적 10% | transfer/01, standard/15 | 교육자료 PDF 34~35쪽, FAQ Q164~Q171 |
| 업무추진비 재증액 | standard/13 | FAQ Q148, 교육자료 PDF 30·34쪽 |
| 승인 마감일 | 확인사항.md, transfer/01 | 교육자료 PDF 35쪽 |
| 편성 기준 예산과 에듀파인 | 교육자료 PDF 36쪽 | transfer/01 사례4 |

파일명은 파일목록.json에서 접두어로 찾습니다. JSON 전체를 매번 읽을 필요는 없습니다.
FAQ는 질문번호별 파일이며, 질문 내용을 찾을 때 폴더 내 키워드 검색을 사용합니다.
원문검색.jsonl은 312개 전체 PDF 페이지의 검색용 저장소입니다. 통째로 모델에 넣지 말고 키워드로 찾은 페이지만 읽습니다. 이미지뿐인 페이지의 내용은 이 텍스트 검색에 잡히지 않을 수 있습니다.

## 적용 원칙

문서 날짜만으로 다른 규정을 덮어쓰지 않습니다. 해당 연도·학교유형·예산 재원·특례 적용범위를 확인합니다. 근거가 충돌하거나 분류가 불명확하면 확인 필요로 남깁니다. AI 의견이 있다는 이유만으로 경고를 해제하지 않습니다. 이 꾸러미는 원문 검색용이며 모든 규정을 검증 완료한 자동판정 규칙집은 아닙니다.
