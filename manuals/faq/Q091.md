Q91 2인의 선생님이 각각 1개 과정[A과정 “가” 업체], 2개 과정[A과정 “나, 
다” 업체, B과정 -“라”업체) 직무분석을 한 경우 수당은 얼마인가요?
 직무분석 수당은 업체당이 아닌 과정당 수당을 지급하므로 1명의 선생님( I )
은 20만원, 다른 1명의 선생님(U)은 30만원의 수당 지급이 가능합니다.
 - ( I )선생님: A과정의 “가”업체: 과정당 지급이므로 20만원
 - (U)선생님: ( I )선생님과 동일 맞춤반 A과정의 직무분석을 하였으나 직무
분석업체가 ( I )선생님 “가”업체, (U)선생님 “나, 다”업체로 각각 상이하므로 ( I )
선생님, (U)선생님 모두 20만원 수당 지급이 가능하고, (U)선생님은 B과정
(“라”업체)의 직무분석도 하였으므로 10만원 더하여 총 30만원 수당 지급이 
가능합니다
※ 복수 과정의 직무분석에 참여하는 경우 1개 건 이후 건에 대해서는 수당의 1/2만 지급 가능
