# sme-voc-budget

중소기업 특성화고 인력양성사업 예산업무 통합 스킬입니다.

## 설치

1. 이 저장소의 `sme-voc-budget-reviewed.zip`을 다운로드합니다.
2. 압축을 풀어 `sme-voc-budget` 폴더를 사용 환경의 스킬 폴더에 설치합니다. Codex의 기본 위치는 `~/.codex/skills/`입니다.
3. `$sme-voc-budget`으로 호출합니다. 다른 환경에서는 해당 환경의 스킬 등록 방식을 사용합니다.

이 저장소는 설치용 ZIP 배포본을 제공합니다. ZIP 내부에 SKILL.md, 업무별 지침, 스크립트, 빈 양식과 매뉴얼 검색 자료가 포함됩니다.

## 작업 순서

학교 예산자료 → 표준 원장 작성 → 검산 및 오류 수정 → 작업자 원장 검토 → 대상 서식 작성 → 작업자 최종 검증.

## 지원 업무

- 예산 원장 작성·검증: XLSX 및 확인사항
- 사업계획서 예산: HWPX 및 확인사항
- 전용신청서: HWPX 및 확인사항. 생성 스크립트는 표준 원장 1~4차를 지원합니다.
- 예산 및 전용편성내역 입력자료: XLSX, 복붙위치, 확인사항
- 중간정산보고서: 기존 양식의 대상 수치 입력. 실제 집행자료와 기준일별 승인 이력이 별도로 필요합니다.

## 실행 조건과 확인 범위

Python 의존성은 ZIP 내부 requirements.txt를 사용합니다. RHWP는 필수가 아닙니다. HWPX의 최종 배치는 한글 등 호환 편집기로 확인해야 하며, Windows 한글 COM용 보조 스크립트를 포함합니다. 스킬 설치만으로 Python이나 한글이 설치되지는 않습니다.

매뉴얼은 관련 주제별 추출문으로 제공하며 원본 PDF는 포함하지 않습니다. 표·이미지·해석이 불명확하면 해당 연도 공식 원문과 대조해야 합니다. 다른 연도나 학교 유형에 규칙을 일률 적용하지 않습니다.

자동 검산과 작업자 최종 검증은 별개입니다. 제출 전 원자료·승인 문서·집행 증빙과 산출물을 대조해야 합니다. 누락된 금액·승인·집행 사실을 임의로 확정하지 않습니다.
